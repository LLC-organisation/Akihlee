2. Workflow: Receipt Capture Pipeline

1
Upload & Ingestion: User submits document via Web, WhatsApp, or Email.
2
Storage & Event: Core API validates file, stores in S3, creates metadata, and queues document.received event.
3
Async OCR Extraction: Worker processes image, runs field extraction, and validates confidence scores.
4
Validation & Human Review: High-confidence records update draft journal entries; low-confidence records route to Review Queue.
5
Posting & Audit: Approved entries post to double-entry ledger and generate append-only audit events.

3. Architectural Guardrails

Financial Integrity: Double-entry bookkeeping with DECIMAL/NUMERIC database types. No binary floating-point math.
AI Safety: LLMs act as orchestrators invoking explicit, read-only system tools. High-impact actions require user approval.
Tenant Isolation: Every database record carries tenant context enforced via server-side authorization filters.
Auditability: Material changes generate immutable, append-only audit logs with unique correlation IDs.
